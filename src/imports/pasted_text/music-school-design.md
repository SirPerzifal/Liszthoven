# Premium Music School Website & Portal Design

Create a modern, elegant, luxury music school platform consisting of both:

1. Public Marketing Website
2. Parent Portal
3. Student Portal
4. Teacher Portal

There is NO Admin Portal required in this design.

The design should be production-ready, fully responsive (Desktop, Tablet, Mobile), component-based, backend-friendly, and suitable for a real-world music academy.

# Registration Flow

Registration is ONLY for creating a Parent Account.

Do NOT ask for:

* Student Information
* Program Selection
* Teacher Selection
* Schedule Selection

during registration.

Keep registration simple and frictionless.

Registration Steps:

Step 1
Parent Information

* Full Name
* Mobile Number
* Email Address
* Password

Step 2
Verification

* Email Verification
  OR
* OTP Verification

Step 3
Account Created

Redirect to Parent Dashboard

---

# Parent Onboarding After Login

Once logged in, parents complete setup inside the portal.

Suggested onboarding checklist:

1. Complete Profile
2. Add Child
3. Choose Branch
4. Select Program
5. Select Teacher
6. Confirm Enrollment
